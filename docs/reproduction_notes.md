## 3. 必须统一的单位和约定

时间用秒，距离和深度用米，角速度用 rad/s，事件光流用 pixel/s。图像坐标 `u` 向右、`v` 向下，光学相机坐标 `X` 向右、`Y` 向下、`Z` 向前；深度是 `Z`，不是到光心的欧氏距离。

位姿为 `T_event_object`：将物体局部坐标变换到事件相机坐标。四元数保存为 `[qx,qy,qz,qw]`。角速度在事件相机坐标系表达，因此旋转增量左乘当前方向：`R_next = Exp(ω Δt) R`。

### 3.1 `v_o` 不等于物体中心的平移速度

根据论文式 (4) 的定义，对于任意刚体点 `P`，

```text
P_dot = v_o + ω × P
t_dot = v_o + ω × t
v_o   = t_dot − ω × t
```

所以若用物体中心轨迹差分得到 `t_dot`，必须先减去 `ω × t` 再放入速度状态；直接使用 `t_dot` 会在纯旋转时引入伪平移。式 (12) 的平移一阶传播也必须包含叉乘项。这里的状态是相机坐标表达的物体空间速度，不能直接套用相机自身运动引起的静态场景光流符号。

### 3.2 式 (2) 和式 (7) 的时间量纲

式 (2) 的位移除以时间产生 pixel/s，而式 (7) 写为 `J V ΔT`，其结果是 pixel。二者若直接相减，量纲不一致。

本项目选择速度形式 `F_hat = J V`。如果输入来自逐帧位移光流，应先除以对应帧间隔再转换成 pixel/s；也可以在另一实现中将观测和预测一起乘以同一间隔，但不能只在预测端乘时间。本文将这个选择视为对论文记号歧义的消解，不声称作者实际代码采用了同一方式。

### 3.3 式 (8) 的旋转项符号

令 `a = u − cx`、`b = v − cy`。从针孔投影以及上面的 `P_dot = v_o + ω × P` 直接微分，得到：

```text
J_v = [ fx/Z,    0, −a/Z ]
      [    0, fy/Z, −b/Z ]

J_ω = [ −a*b/fy,       fx + a*a/fx, −b*fx/fy ]
      [ −fy − b*b/fy,  a*b/fx,       a*fy/fx ]
```

用户提供的 PDF 和 arXiv v1 的式 (8) 把第二行第一项印成正号；这与以上统一约定下的微分结果不一致。本项目采用推导得到的负号，并以三维点运动后重新投影的有限差分校验各个轴的符号。由于没有作者源码，这里只能识别为疑似排版或约定不一致，不能断言作者程序也有这个问题。

### 3.4 法向约束与“2-DoF”的含义

当 `F != 0`，令 `n = F / ||F||`，论文式 (9) 的向量残差可写成：

```text
r = n * (n.T @ J @ V − ||F||)
```

因此等价的标量观测是 `z = ||F||`、`H = n.T @ J`。这是一个秩为 1 的方向投影：每个边缘光流不是两条独立约束。论文的“2-DoF”描述的是像平面方向和幅值信息相对于此前时间差观测的增加，不意味着孔径问题消失。

六维速度需要足够多、方向和空间分布足够丰富的有效光流与深度才能观测。只增加重复的平行边缘事件数量不能保证满秩；应检查观测矩阵秩和条件，而不是仅检查事件数量。零光流不能归一化为法向，需要跳过。

### 3.5 三元组搜索与式 (3) 的有限候选求解

当前实现把最新事件放在三元组末端，在同极性历史中搜索等间距像素 `x, x−d, x−2d`。设相邻时间差为 `Δt1`、`Δt2`，一致性阈值作用于无量纲量 `2|Δt1−Δt2|/(Δt1+Δt2)`。这是对式 (1) 的可执行解释，不是论文直接公开的 `ξ` 设置。

默认空间步长搜索半径为 2 像素，每像素、每极性保留 3 个时间戳；三元组总跨度不超过 50 ms。每个事件至多保留 6 个不同候选，按时间间隔一致性优先筛选；每个 8 × 8 网格最多使用最近 20 ms 内的 8 个候选集合。式 (3) 在保留的集合并集上用欧氏距离精确比较，并非对单个光流取中位数；相同代价时选择模长较小的候选。由于网格还保留历史三元组，最早支撑事件相对当前事件可能达到 70 ms；加上批次等待后，输出年龄还会增加。搜索子集、截断和并列选择均是本项目的工程取舍。完整参数以 `ev6d config` 输出为准。

## 4. 未公开细节与本项目的实现边界

目标论文明确给出衰减系数 `α = 0.5` 和实验中的 5 Hz 全局位姿输入；没有给出可直接重建实验的全部超参数。以下部分不能从论文唯一确定：

- 三元组搜索的空间尺度、时间窗口、容差 `ξ` 的操作定义、历史长度，以及去重/同极性处理。
- 式 (3) 的网格尺寸、事件数、更新时间，以及计算预算受限时如何裁剪候选集合。
- 速度滤波的更新间隔；`α = 0.5` 是每次预测的系数，若不说明参考时间间隔，改变批次长度就会改变衰减率。
- 全部初始协方差、过程噪声和观测噪声，噪声是否随时间缩放，UKF 的 sigma 点参数。
- 式 (10) 的二维残差如何归约、`b` 是否在线估计，以及权重如何进入 KF。当前实现的这些细节应以配置与代码为准，不冒充作者参数。
- 目标对象从事件中分离的方法、遮挡处理、背景运动、多物体关联以及完全丢失后的重新定位。
- 双相机同步误差、事件相机畸变、深度配准与遮挡、DOPE 使用的模型版本、网络置信度和真实推理延迟。
- Unreal 场景、对象轨迹、事件生成器设置、原始数据、训练权重版本以及完整评估脚本。

本项目补充了如下可审查的工程约束：

1. 事件进入三元组算法前做去畸变，并四舍五入到整数网格。这会引入像素量化误差；标定精度和网格选择会影响光流方向。
2. 深度通过反投影、外参变换、重投影和近点遮挡处理映射到事件相机；无效或过旧深度不用于速度校正。没有实现运动补偿深度或稠密深度补全。
3. 光流网格和目标分割是两件事。默认目标掩膜依赖已知模型及初始位姿，不能自动从任意场景发现新物体。
4. 没有事件可能表示静止，也可能来自低纹理、遮挡或传感器丢包。速度衰减是先验，不是检测到静止的证据。
5. 位姿观测使用独立的采集时间 `t` 和到达时间 `available_at`。当前版本显式拒绝过时观测，没有实现回滚重放或乱序观测平滑；真实 DOPE 推理延迟需要额外设计。将旧位姿的时间戳改成到达时间会掩盖这个问题，应避免。
6. UKF 采用四元数流形处理，不在四个分量上直接作普通加减。旋转误差是三维量，因此 `[位置误差, 旋转误差]` 的协方差为 `6 × 6`，不是 `7 × 7`。
7. 位姿传播使用恒定空间速度的精确 SE(3) 积分，细化论文式 (12) 的一阶平移近似。预测以位姿和速度协方差构造增广 sigma 点，并将旋转更新后的协方差重新映射到新的切空间。过程噪声按时间缩放；速度衰减与噪声以 10 ms 为参考，额外的异步观测时刻不会改变速度衰减先验。
8. 式 (10) 在本实现中使用每个光流残差的模长、其中位数、固定尺度 `b=20 pixel/s`，权重进入 `R_eff = sigma_flow² / L`。这是单次权重计算，不包含参考 ERL 的多模型估计。
9. 合成测试揭示空历史的启动阶段可能只产生错误的快速三元组，真实慢运动需要更多时间支撑。主流程默认先积累 `flow_warmup_s=0.05` 秒历史，再使用光流更新；可设为 0 禁用。此保护不是论文声明的机制，会增加启动等待时间，也不解决所有错误匹配或长时间断流后的恢复问题。
10. 默认不进行位姿创新门限拒绝（`pose.gate_threshold=null`），与论文未明确描述该策略相符。可配置正数阈值启用卡方形式的马氏距离门控，但过低的门限会拒绝高速运动时的正确观测，尤其是 `pose_only` 模式。启用时必须结合过程/观测协方差校准，不能将拒绝全部纠正当成鲁棒性。

## 5. 如何解释测试结果

`synthetic.py` 使用带纹理的长方体光线投射得到 RGB-D，再通过对数亮度阈值产生事件。它有独立真值供指标评估，且模拟的低频带噪位姿来源明确标记。它用于发现坐标、量纲、时序和缺测处理错误；不能替代论文的 Unreal/YCB 数据，也不能检验真实 DOPE 网络或真实传感器噪声。

基于解析光流的几何测试可以验证矩阵和滤波器，但不能证明事件匹配本身准确。必须同时查看由原始事件产生的有效光流比例、法向残差、速度可观测性、位姿误差以及缺测/异常值场景；某个合成场景中融合优于低频位姿基线，也不能推断所有真实场景都有同样改善。

论文 Discussion 明确说明实验离线进行。当前 Python 实现的离线运行耗时、吞吐量及事件来源年龄也应分别报告；它们不是传感器到控制器的实测延迟，不构成硬实时保证。完成精确实验复现仍需要作者数据、完整配置及外部位姿估计器，或重新采集有标定、有同步记录、有真值的数据集。

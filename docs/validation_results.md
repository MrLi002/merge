## 实现取舍与后续风险

初次整体验证暴露了空事件历史中的错误快速三元组、以及过严位姿门限导致正常观测被拒绝。最终默认配置增加 50 ms 启动历史积累，并将位姿门限改为可选。它们属于依据这组合成数据发现问题后的工程修正，因此这里没有独立留出测试集，也不能推断真实数据泛化精度。

当前仍需改善错误匹配、低分辨率下的运动歧义、长时间断流恢复以及异常位姿处理。真实 DOPE 的延迟历史观测会被当前流程明确拒绝，接入实机前需实现延迟补偿。Python 光流模块是主要耗时来源，尚未达到实时处理。

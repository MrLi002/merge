原始事件流
    │
    ├─ 历史事件 E[t0-Δt, t0) ─┐
    │                          ├─ 体素化 ─→ E-RAFT ─→ F(t0→t1)
    └─ 当前事件 E[t0, t1) ────┘                         │
                                                       │
t0 深度图 ─→ 配准到事件相机平面 ──────────────────────────┤
                                                       │
t0 目标掩码 ────────────────────────────────────────────┤
                                                       ↓
                                            二维光流观测构建
                                                       ↓
                                             六维速度 Kalman Filter
                                                       │
                                              ξ = [vO, ω]
                                                       │
                                                       ↓
初始位姿 ───────────────────────────────────────→ 位姿 UKF预测
                                                       ↑
                                                       │
RGB(tk) → 外部 DOPE → poses.csv → 延迟校正与历史重放 ─────┤
                                                       │
                                                       ↓
                                   位置、四元数、线速度、角速度、轨迹





run_dense_tracking
    │
    ├─ E-RAFT.infer() / FlowCache.load()
    │        ↓
    │   F(t0→t1)
    │
    ├─ source_geometry()
    │        ↓
    │   t0深度 + t0掩码
    │
    ├─ DenseVelocityKF.update()
    │        ↓
    │   六维速度 ξ = [vO, ω]
    │
    ├─ PoseHistory.predict_to()
    │        ↓
    │   PoseUKF.predict_to()
    │        ↓
    │   位置和四元数预测
    │
    └─ PoseHistory.update()
             ↓
        poses.csv低频位姿校正
        + 延迟历史重放





命令	                                用途	                    是否为 E-RAFT 主流程必需
check-data	            检查事件、深度、掩码、标定和时间戳	    建议使用
track-dense	            E-RAFT 稠密光流与6DoF跟踪	            必需
evaluate	            评估位姿与速度；有GT时计算误差	        结果评估需要
reproject	            把估计位姿投影到RGB图像检查	        建议使用
visualize	            绘制轨迹和误差可视化	                可选
precompute-flow	        提前计算并缓存E-RAFT光流	            可选，离线实验用
train-flow	            独立训练或微调E-RAFT	                训练时使用
evaluate-flow	        评估E-RAFT checkpoint	            光流评测时使用
evaluate-flow-cache	    评估已缓存的光流	                    可选
convert-dope	        把外部DOPE结果转换成 poses.csv	    使用真实DOPE时需要
generate	            生成简单合成测试数据	                测试用
generate-ycb	        生成YCB合成RGB-D/事件数据	            数据生成用
fetch-ycb	            获取YCB模型资源	                    生成YCB数据时使用
flow-fixture	        生成DSEC格式的小型训练测试数据	        训练管线测试用
dense-config	        输出默认稠密跟踪配置	                可选
config	                输出旧版跟踪配置	                    可选
track                   原来保留的事件三元组光流基线	        可选
